# Gestor de Procesos Legales

Sistema web desarrollado con React, Node.js y MongoDB para la gestión automatizada de procesos judiciales.

## Funcionalidades

- CRUD de procesos
- Login JWT
- Procesos pendientes
- Cálculo de días hábiles
- Análisis de PDFs judiciales
- Detección automática de actuaciones

## Tecnologías

- React
- Node.js
- Express
- MongoDB
- Tailwind CSS
